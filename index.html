Head Kit

Add your own 3D head to any website

Upload a head model and its picture. You get one small piece of code to paste into your site. The head sits in a corner, follows the cursor, and opens a menu with colour themes when clicked.

  • Tumblr
  • WordPress
  • Blogger
  • Neocities
  • Plain HTML
1

Get your two files

You need a head model (.obj) and the picture that wraps around it (.jpg, .png or .bmp). If you have a Blender file, export it like this:

  1. Open the .blend file in Blender (free at blender.org).
  2. Choose File > Export > Wavefront (.obj). Tick Triangulated Mesh, keep Materials ticked, and save.
  3. For the picture, open the Shading tab, click the picture box (it shows the file name), then choose Image > Save As.

Models from other programs work too, as long as they have a UV map. That’s what tells the picture where to go on the head.

2

Build your snippet

Starting menu colour

Visitors can switch colours themselves from the head’s menu. This only sets the first one they see.

Move your mouse around the preview and click the head to open the menu. If the face looks backwards or sideways, change the direction above and the preview updates.

3

Paste it into your site

You don’t replace anything and you don’t need a special theme. The snippet is a single <script> block. Paste it on its own line just above the closing body tag (</body>), which is the very end of your page:

<html>
  <head> … </head>
  <body>
    … your page content …
    <!-- Head Kit: paste here -->  </body>
</html>

If your site doesn’t let you edit the page HTML, look for a place to add a custom footer script. Pick your platform:

  1. Open your blog, click Edit appearance, then Edit theme, then Edit HTML.
  2. Click inside the code box and press Ctrl+F (or Cmd+F on a Mac). Search for </body>.
  3. Click at the start of that line so your cursor sits just before </body>. Press Enter to make an empty line, then paste the snippet. Keep your existing theme code as it is.
  4. Click Update preview, then Save.
  5. Open your real blog address in a new tab. Tumblr’s preview often ignores mouse movement, so the head only follows your cursor on the live page.

The safest way is a free header and footer plugin, so a theme update never wipes your code.

  1. In your dashboard, go to Plugins > Add New and install a header/footer code plugin (for example WPCode), then activate it.
  2. Open the plugin’s Header & Footer settings.
  3. Paste the snippet into the Footer box and save.

Prefer editing files? With a classic theme, open Appearance > Theme File Editor, choose footer.php, and paste the snippet on its own line directly above <?php wp_footer(); ?> or </body>. Use a child theme so updates don’t erase it.

Blogger’s template editor rejects some characters in scripts, so use a gadget instead:

  1. In Blogger, open Layout.
  2. Click Add a Gadget in a footer or sidebar area, and choose HTML/JavaScript.
  3. Paste the whole snippet into the content box, then Save and Save arrangement.

The head floats in a corner of the screen, so it doesn’t matter which area holds the gadget.

For Neocities, GitHub Pages, or any site where you control the files:

  1. Open your page’s .html file in an editor.
  2. Scroll to the bottom and find </body>.
  3. Paste the snippet on a new line directly above it, then save and upload.

Want the head on every page? Paste it into each page, or into the shared footer or template file if your site has one.

Website builders usually hide the HTML, but most have a spot for custom code. Menu names change over time, so look for one of these in your site settings:

  • Wix: Settings > Custom Code, add the code to Body – end on all pages.
  • Squarespace: Settings > Advanced > Code Injection, paste into the Footer box.
  • Webflow: Site settings > Custom code, paste into Footer code.
  • Anything else: search the help pages for “custom code”, “footer script” or “code injection”.

Some builders only allow custom code on paid plans, and a few (such as link-in-bio pages or note apps) block scripts completely. If yours does, the head can’t run there.

4

What visitors can do

Hover over the head and the cursor turns into a pointer. Clicking it opens a round menu with these choices:

  • Hide head removes it, and a small Show head button appears to bring it back.
  • Move left / Move right sends it to the other corner.
  • Colour dots change the menu theme: blue, white, black, pink, green, purple, orange, red, yellow or teal. The head’s hover outline changes to match.
  • Close or the Esc key closes the menu.

Choices are remembered in each visitor’s own browser. The colour themes only affect the head’s menu, never the rest of your site.

?

If something looks wrong

Nothing shows up on my site

Check that the snippet sits above </body> and that you pasted all of it, from <script> to </script>. Make sure you used an HTML or code editor, not a visual one that strips scripts. If you hid the head earlier, look for the Show head button at the bottom of the page. Some sites, and some mobile apps, block custom scripts. Your browser also needs WebGL, which almost every current browser has.

The face is backwards or sideways

Change Which way does the head face? in Step 2. The preview updates and the snippet is rewritten. Copy it again and replace the old one.

It says my model has no UV map

The model needs a UV map so the picture can wrap around it. In Blender, tick UV in the export settings, or check that the model has been unwrapped.

The colours look wrong or the head is plain

You may have picked a different picture than the one the model uses. If the model uses several pictures, this kit can only use one, so pick the main face picture.

My site won’t accept the code, or loads slowly

Very detailed models make the snippet large, and some editors limit how much code you can paste. Simple models with a few hundred triangles work best. Pictures are shrunk to 256 pixels wide automatically.

The head covers part of my page

Visitors can hide it or move it from the menu. You can also make it smaller: near the top of your snippet, find the line starting var SIZE = and lower the two numbers.

Can I use heads from a game?

Fan sites do it all the time, but the models and pictures belong to the people who made them. If you plan to sell anything or run a bigger site, check the rules first.
